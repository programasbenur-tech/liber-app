# LIBER ❤️ — Visual Design System

## 1. Brand Identity
- **Title:** `LIBER ❤️`
- **Subtitle (ES):** `¿Cómo está el semáforo del amor hoy?`
- **Subtitle (PT-BR):** `Como está o semáforo do amor hoje?`
- **Tone:** Romantic, witty, warm, modern, zero clinical stiffness, zero vulgarity.

## 2. Color Palette
- **Primary Gradients:** Soft romantic rose (`#ff4d79`), coral (`#ff758c`), orchid purple (`#9b5de5`), and warm blush backgrounds (`#fff5f8` → `#fdf2f8` → `#f5f3ff`).
- **Traffic Light Semantics:**
  - 🟢 **LIBER:** Emerald glow `#10b981` / `#34d399`
  - 🟡 **CASI LIBER:** Warm amber glow `#f59e0b` / `#fbbf24`
  - 🔴 **ANTI LIBER:** Soft coral-rose `#f43f5e` / `#fb7185` (warm and affectionate, never harsh/punitive)
- **Surfaces:** Frosted glass rounded cards (`rounded-3xl`, `backdrop-blur-md`, `bg-white/85`, subtle rose borders `border-rose-100`).

## 3. Typography & Accessibility
- **Font:** `Plus Jakarta Sans` / system sans-serif with large, readable mobile-first hierarchy (`16px` base, `20px–32px` headings).
- **Touch Targets:** Minimum `48px` height on all interactive buttons and quiz options.
- **Contrast:** High-contrast dark plum (`#2d1635`) text on light blush cards.

## 4. Motion & Micro-interactions
- Gentle floating hearts background animation (`animate-float`).
- Pulsing glow ring around the active traffic light bulb.
- Smooth card transitions in the questionnaire and animated Quiz Roulette spinner.
